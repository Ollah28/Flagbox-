# Flagbox

**Sourced red flags for public tenders. The committee decides.**

Flagbox is an open-source agent for the Bid Box Challenge (Governance track). It screens a Kenyan public buyer's published procurement awards (Open Contracting Data Standard) for integrity red flags. Every finding cites the exact public record it came from, and the agent drafts an audit-prep memo that a named human must approve before it is filed. **Flagbox never awards, recommends or accuses.**

> Status: early development. See [PLAN.md](PLAN.md) for progress and [SPEC.md](SPEC.md) for the design. This README will document setup, the demo, and honest limitations as they are built.

**Data half:** built on real award data (tenders and awards), not bid documents.
